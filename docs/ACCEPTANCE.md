상태: 전체 릴리스 판정은 **NOT_RUN**. D12의 AC별 실제 충족 상태와 테스트 이름은 [TEST_REPORT](TEST_REPORT.md)의 D12 매트릭스를 따른다. D11은 키보드 핵심 흐름·포커스·100개 이슈/3개 폭의 화면을 확인했다. 실제 OS IME·스크린리더·외부 사용자·실제 OAuth·새 clone/새 DB·원격 CI는 자동화 통과와 구분한다. 신규 /demo 화면만 후속으로 옮겼고 기존 실제 앱 시연·재현 문서는 유지한다.

## 성능 관찰 — 목표이지 결과가 아님

- 합성 이슈 100개, 서로 다른 사용자 2명, production build, 기록된 브라우저·장비·네트워크.
- 낙관적 이동: 응답을 1초 지연시켜도 응답 전에 카드가 새 열에 보이고 저장 중임을 알 수 있는지.
- 전파 지연: 상태 변경 20회 이상 측정 후 중앙값·최댓값을 기록. 2초 이내를 초기 목표로 삼되 미달하면 원인과 한계를 공개.
- React Profiler는 실제 입력 지연/불필요한 대규모 렌더링이 관찰될 때만 사용. 최적화 수치는 동일 조건 전후 측정이 있을 때만 기재.
- 고정된 sleep으로 성공을 기다리지 말고 상태·네트워크·DOM에 대한 조건 기반 대기를 사용한다.

## 결과를 인정하지 않는 예

- 브라우저 두 탭이 같은 계정인데 역할 격리 검증이라고 기록.
- mock WebSocket 이벤트만 발생시키고 실제 실시간 협업 검증이라고 기록.
- DB에 도달하기 전 요청 취소만 시험하고 commit 후 응답 유실도 검증했다고 기록.
- 테스트 실행 환경이 없는데 코드를 읽었으므로 PASS 처리.
- snapshot 전체 복원으로 다른 사용자의 변경을 지웠는데 카드가 돌아왔다는 이유로 롤백 성공 처리.
